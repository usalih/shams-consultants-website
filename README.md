# SHAMS CONSULTANTS LIMITED — Website

A responsive, static corporate website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. For local development, you can also run:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Included
- Responsive corporate landing page
- About, services, sectors, approach and contact sections
- Mobile navigation and back-to-top interaction
- Company D-U-N-S number and address
